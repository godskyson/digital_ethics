# 디지털 윤리

디지털 윤리 수업 자료와 활동 결과물을 모아 두는 저장소입니다.

## 다루는 주제

- 개인정보 보호와 디지털 발자국
- 저작권과 공정 이용
- 사이버 폭력 예방과 온라인 예절
- 허위 정보 판별과 미디어 리터러시
- 인공지능 윤리

## 폴더 구성

| 폴더 | 내용 |
| --- | --- |
| `docs/` | 수업 계획, 활동지 등 문서 자료 |
| `slides/` | 수업용 발표 자료 |
| `activities/` | 학생 활동 결과물 |

> 폴더는 자료가 추가되는 대로 만들어 갑니다.

## 사용 방법

```bash
git clone https://github.com/godskyson/digital_ethics.git
```

자료를 추가한 뒤에는 다음 순서로 올립니다.

```bash
git add .
git commit -m "자료 추가: <내용>"
git push
```
